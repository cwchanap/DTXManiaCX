## Architecture and scope guardrails for the implementation agent

**Reuse rather than rebuild:** `PerformanceStage`, `PerformanceUILayout`, `NotationStripLayout`, `DrumStaffMapping`, `SkillPanelDisplay`, `ScoreDisplay`, `ComboDisplay`, `JudgementManager`, existing popup and timing conventions, game clock, current texture/font infrastructure.

**Do not touch:** notation quantization/scroll rate/engraving, the hit marker x=220 or key-mask x=0..195, input binding/parser/audio, saved preference/telemetry shape, score/gauge/skill formulas, or DTXManiaNX. Do not add custom art/SFX or a new rendering framework.

**Decision locked for this PR:** no notehead tint/fade. A >200ms Miss happens after the notehead is hidden by the key mask. A clear popup/label response is feasible now; notehead lifetime/geometry deserves a **separate, later ticket** only if playtests demand it.

**Time-box rule:** if extending current sprite popups or relocating legacy score digit sprites becomes costly, render that one Tab presentation with the existing managed font and keep its manager/data source unchanged. Prioritize correctness, legibility, and Lanes regression over exact mockup decoration.
