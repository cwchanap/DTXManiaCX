- Existing canonical config round-trips, existing notifications, persistence guards, collection handling and visuals are preserved; obsolete INI/row migrations gone.
- Fresh startup, preseeded E2E and recorder sandbox all use config.db; real source DB remains unchanged, no INI required; tests and actual MCP workflow prove persistence across restart and gameplay.
- Same-skin System/Drums screenshot parity verified by agent; no human acceptance gate. All changes and evidence in the same implementation PR, no extra PR or generated artifacts.
