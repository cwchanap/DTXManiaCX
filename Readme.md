DTXManiaCX
===========

[![Ask DeepWiki](https://deepwiki.com/badge.svg)](https://deepwiki.com/cwchanap/DTXManiaCX)

DTXMania rewritten in .NET 10 with MonoGame.

The bundled CX Neon skin lives in `System/` and ships with release builds; see
[`System/README.md`](System/README.md). Custom skins live in the app-data
`System/` folder and take precedence while selected.
